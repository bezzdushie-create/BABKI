# Ниша: недвижимость и интерьер

**Контент:** маршрут по объекту; детали планировки; «кому подходит»; район; этапы ремонта; moodboard; визуализация идеи с явной пометкой «концепт».

**Стек:** GPT — сценарий и вопросы покупателя; Higgsfield — cinematic walkthrough/атмосфера; Doitong — объяснение и озвучка; YouTube — длинный обзор; Instagram/TikTok — тизеры; Timeweb — страница объекта/портфолио; Telegram — подборки.

**Автоматизация:** факты объекта из проверенной карточки → сценарий → визуальные вставки → ручная сверка площади, цены, адреса и статуса → публикация → заявка на просмотр.

**Пакет:** 1 длинный обзор + 5 коротких роликов + страница объекта.

**Метрики:** квалифицированные запросы, записи на просмотр, стоимость лида, время на странице.

**Риски:** выдавать AI-визуализацию за существующее состояние, искажать размеры/вид, публиковать адрес и личные данные без разрешения.
