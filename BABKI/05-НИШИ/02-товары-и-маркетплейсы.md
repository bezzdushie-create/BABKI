# Ниша: товары и маркетплейсы

**Клиенты:** D2C-бренды, продавцы маркетплейсов, небольшие интернет-магазины.

**Контент:** проблема → продукт → демонстрация; 3 сценария использования; распаковка; сравнение без недоказуемых заявлений; детали/материал; UGC-концепт с явно синтетическим персонажем.

**Стек:** GPT — боли/хуки/варианты рекламы; Higgsfield Marketing Studio — product shots и варианты; Doitong — сцены, голос, субтитры; Instagram/TikTok/Shorts — тест креативов; сайт Timeweb — каталог/лендинг; ChatPlace — подбор товара и FAQ.

**Автоматизация:** карточка товара/ссылка → извлечение проверенных характеристик → 5 углов подачи → тестовые первые кадры → 3 ролика → ручная проверка характеристик → публикация.

**Пакет:** 3–5 креативных концепций, по 2 хука на каждую, 9:16 и версии без текста.

**Метрики:** удержание, CTR ссылки, добавление в корзину, стоимость заказа, возвраты.

**Риски:** выдуманные свойства, поддельный UGC/отзывы, чужие товарные знаки, несоответствие AI-изображения реальному товару.
