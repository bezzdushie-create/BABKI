# Ниша: эксперты и образование

**Клиенты:** преподаватели, консультанты, авторы курсов, B2B-эксперты.

**Контент:** один вопрос — один ответ; ошибка/миф; мини-кейс; схема на экране; разбор инструмента; фрагмент урока; приглашение на консультацию.

**Стек:** GPT — структура и упрощение; Grok — свежие дискуссии; Doitong — объясняющие сцены/озвучка; Higgsfield — выразительные метафорические вставки; YouTube — поиск и длинные разборы; Instagram/TikTok — вход; Telegram — прогрев; сайт — программа и заявка.

**Автоматизация:** база вопросов аудитории → кластер → сценарии → эксперт подтверждает факты → ролики → кодовое слово → чек-лист → квалификация.

**Пакет:** 12 Shorts/Reels из одного 60–90-минутного интервью + 30 идей.

**Метрики:** сохранения, досмотры, подписки после просмотра, скачивания материала, заявки.

**Риски:** галлюцинации фактов, отсутствие источников, медицинские/юридические/финансовые советы без проверки, синтетический «эксперт» вместо реального автора.
