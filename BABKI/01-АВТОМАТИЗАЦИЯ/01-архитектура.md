# Архитектура автоматизации

## Безопасная схема

```text
Тренды/вопросы клиентов
        ↓
База идей → GPT/Grok → сценарий → ручное утверждение
        ↓
Higgsfield или Doitong → монтаж/субтитры → контроль качества
        ↓
Папка READY + карточка публикации
        ↓
официальный Instagram API / одобренный планировщик
        ↓
Reels + адаптированные Shorts/TikTok
        ↓
Комментарий/Direct → ChatPlace → квалификация → CRM/таблица
        ↓
сайт/бриф → созвон/оплата → производство → отчёт
```

## Уровни зрелости

### Уровень 0 — вручную, 1–5 роликов

Проверяется ниша, качество и способность регулярно выпускать контент. Автоматизация пока мешает увидеть слабое место.

### Уровень 1 — шаблоны, 6–30 роликов

Единые карточки идей, промпты, папки, чек-листы, пакетная подготовка сценариев и планировщик публикаций.

### Уровень 2 — связанный процесс

Webhook/интегратор переносит утверждённую карточку в очередь, отправляет уведомления, фиксирует ссылку публикации и метрики. Direct обрабатывает ChatPlace.

### Уровень 3 — API и собственный backend

Doitong/Higgsfield API (если доступен выбранный метод), хранилище объектов, очередь задач, база метаданных, Instagram Content Publishing API, журнал ошибок и ручное подтверждение. Для этого нужен VDS/облачный сервер, а не простой WordPress-хостинг.

## Рекомендуемый стек

- Управление: Notion/Google Sheets/CSV или локальная Markdown-база.
- Оркестрация: n8n на Timeweb Cloud/VDS либо облачный интегратор.
- Хранилище: S3-совместимое хранилище или защищённое облако.
- Производство: GPT + Higgsfield/Doitong.
- Публикация: Meta Business Suite или официальный API/проверенный партнёр.
- Лиды: ChatPlace → Telegram/почта → CRM/таблица.
- Аналитика: нативная статистика площадок + еженедельная таблица.

## Статусы контента

```text
IDEA → RESEARCHED → SCRIPTED → APPROVED → GENERATING
→ EDITING → QC → READY → SCHEDULED → PUBLISHED → MEASURED
```

Переход в `READY` разрешён только после проверки человеком. Ошибка публикации не должна автоматически создавать дубликат: сначала проверить permalink/ID операции.

## Что нельзя автоматизировать без контроля

- факты и медицинские/финансовые/юридические советы;
- использование лиц, голосов, брендов и музыки;
- ответы на конфликтные или персональные обращения;
- возвраты, гарантии и договорные обещания;
- массовую генерацию «почти одинаковых» видео;
- удаление исходников и клиентских данных.
