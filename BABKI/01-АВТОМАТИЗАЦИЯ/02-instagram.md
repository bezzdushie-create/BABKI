# Instagram: публикация, комментарии и Direct

## Подготовка

- Профессиональный аккаунт (Business или Creator).
- Права владельца и включённая 2FA.
- Для своего API-приложения: Meta Developer app, Instagram Login, нужные разрешения и токены в защищённом хранилище.
- Для простого старта: Meta Business Suite или сервис, работающий по официальному API.

Meta документирует профессиональные аккаунты и разрешение `instagram_business_content_publishing`; актуальные требования нужно проверять при настройке.

## Надёжный цикл публикации

1. Экспортировать вертикальное видео без чужого водяного знака.
2. Проверить безопасные зоны, звук, субтитры, обложку и описание.
3. Поставить дату/время и уникальный ID карточки.
4. Опубликовать официальным способом.
5. Получить ID/permalink и записать его в карточку.
6. Через 15–30 минут проверить публикацию вручную.
7. Собрать метрики через 24 часа, 72 часа и 7 дней.

## ChatPlace: воронка из комментария

Пример:

```text
Reels: «Напишите ПЛАН»
→ публичный короткий ответ
→ Direct: обещанный материал
→ вопрос 1: ниша
→ вопрос 2: цель и объём
→ ветка A: скачать чек-лист
→ ветка B: оставить заявку
→ уведомление менеджеру в Telegram
```

В сообщениях не притворяйтесь человеком, если отвечает бот. Собирайте только необходимые данные, сообщайте цель обработки и не выгружайте персональные данные в открытые таблицы.

## Антиспам и устойчивость

- Не писать первым массово и не отправлять одинаковые сообщения всем.
- Уважать окно и правила сообщений Instagram/ChatPlace.
- Ограничить число повторных напоминаний.
- Добавить команду остановки и ручной перевод на менеджера.
- Хранить журнал: триггер, версия сценария, согласие, результат.
- При ошибках API ставить задачу на повтор с задержкой, но не публиковать бесконечно.

## Чек-лист Reels

- [ ] хук понятен без звука;
- [ ] один ролик — одна мысль;
- [ ] текст читается на телефоне;
- [ ] нет ложной фактической сцены;
- [ ] права и согласия проверены;
- [ ] AI-маркировка добавлена, если требуется;
- [ ] один CTA;
- [ ] описание не дублирует ролик дословно;
- [ ] ссылка/кодовое слово работают;
- [ ] финальный файл сохранён вместе с карточкой.
